## 🛠 Cara Instalasi
1.  Unduh file `.ffx` dari repositori ini.
2.  Buka folder **Presets** di direktori Adobe After Effects Anda:
    *   **Windows:** `C:\Users\[Username]\Documents\Adobe\After Effects [Versi]\User Presets`
    *   **macOS:** `/Users/[Username]/Documents/Adobe/After Effects [Versi]/User Presets`
3.  Salin (Copy) file `.ffx` ke dalam folder tersebut.
4.  Restart After Effects Anda.
5.  Cari preset di panel **Effects & Presets** (Shortcut: `Ctrl+5` / `Cmd+5`).

## 💡 Cara Penggunaan
1.  Pilih layer (Shape, Text, atau Solid) di timeline Anda.
2.  Buka panel **Effects & Presets**.
3.  Cari nama preset di kolom pencarian.
4.  Klik dua kali atau tarik (*drag and drop*) preset tersebut ke layer yang dipilih.
5.  Sesuaikan *Keyframes* atau *Effect Controls* sesuai kebutuhan estetika visual Anda.
